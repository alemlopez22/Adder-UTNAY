## How it works
This project implements a 1-bit Full Adder using basic logic gates.

A Full Adder is a combinational digital circuit that performs the addition of three binary inputs:

- **A:** First binary input.
- **B:** Second binary input.
- **Cin (Carry In):** Carry input from a previous addition.

The circuit produces two outputs:

- **S (Sum):** The result of the binary addition.
- **Cout (Carry Out):** The carry output generated by the addition.

The circuit uses XOR, AND, and OR logic gates to calculate the outputs.

The Boolean expressions are:

**Sum:**
`S = A XOR B XOR Cin`

**Carry Out:**
`Cout = (A AND B) OR (Cin AND (A XOR B))`

## How to test
To test the Full Adder, follow these steps:

1. Connect the circuit according to the logic gate configuration.
2. Apply binary input combinations to A, B, and Cin.
3. Observe the Sum (S) and Carry Out (Cout) outputs.
4. Compare the results with the truth table to verify that the circuit works correctly.
